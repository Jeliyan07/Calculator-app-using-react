🧮 React Calculator App
A simple and responsive calculator application built using React JS by Jeliyan Reang.
This app performs basic arithmetic operations with a clean and intuitive user interface — ideal for both learning and practical use!

🚀 Features
Perform basic arithmetic: + - × ÷

Clear and reset function

Responsive design for mobile and desktop

Smooth and fast performance using React's component-based structure

🛠️ Tech Stack
React JS — Frontend framework

JavaScript — Application logic

CSS — Styling (you can mention Tailwind, Bootstrap, or plain CSS if you're using one)
